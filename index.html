📐 Formül ve Özet Kartları

Mol Kavramı

  • • n = m / MA
  • • n = N / NA (NA = 6,02·10²³)
  • • NŞA’da n = V / 22,4

Molarite

  • • M = n / V (L)
  • • Seyreltme: M₁V₁ = M₂V₂
  • • Karışım: M = (n₁ + n₂) / (V₁ + V₂)

pH ve pOH

  • • pH = −log[H⁺]
  • • pOH = −log[OH⁻]
  • • pH + pOH = 14 (25 °C)

Gazlar

  • • PV = nRT (R = 0,082 L·atm/mol·K)
  • • Boyle: P₁V₁ = P₂V₂
  • • Charles: V₁/T₁ = V₂/T₂
  • • T(K) = °C + 273

Atom ve İyon

  • • Kütle numarası A = proton + nötron
  • • Nötr atomda proton = elektron = Z
  • • İyonda elektron = Z − yük

Yoğunluk ve Yüzde

  • • d = m / V
  • • Kütlece % = (m çözünen / m çözelti) · 100

Isı

  • • Q = m · c · ΔT
  • • Suyun öz ısısı: c = 4,18 J/g·°C
